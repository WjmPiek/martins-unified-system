HEAT MAP IMPORT MERGE / NO-DUPLICATE UPDATE

1. Back up the working project.
2. Extract this ZIP into the project root.
3. Allow the included app files to replace the matching files.
4. Commit and push the changes to deploy on Render.

No database migration is required.

Import behaviour after this update:
- Existing Heat Map records that are not in the uploaded file remain untouched.
- Records are compared inside the selected franchise and category.
- MF File is used as the primary service identifier when available.
- A matching record is updated in place when supplied details have changed.
- A matching unchanged record is skipped.
- A genuinely new record is added.
- Repeated rows inside the same uploaded workbook are not added twice.
- Blank incoming values do not erase useful existing values.
- The import result reports Added, Updated and Unchanged/Duplicates totals.

This package also contains the current 57-column Heat Map template and category/service-grouping files so it can be installed as one complete update.
