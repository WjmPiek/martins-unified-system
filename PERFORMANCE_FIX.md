# Royalty overview performance fix

The Royalty Overview page is read-only. It displays the saved monthly figure
and grouped-franchise calculation for the selected reporting period without
recalculating or saving every branch during a normal page visit.

Royalty calculations are still performed when a monthly import is processed
or when an authorised recalculation action is used.

Status meanings:

- **Calculated / Calc**: the current working calculation, based on imported
  figures and the applicable agreement scale.
- **Published**: the calculation has been released as the official franchise
  record for that period. It remains visible and is not changed merely by
  opening the overview page.
