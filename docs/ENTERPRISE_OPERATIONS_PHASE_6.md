# Phase 6 - Enterprise Operations Centre

Adds an Admin/Finance control room at `/admin/operations`.

## Included

- Operations Centre navigation link for Admin/Finance users
- System health cards
- Import job status and Needs Review list
- Published monthly period summary
- Performance cache status
- Rebuild latest period cache button
- Invalidate cache button
- Live events overview
- Latest audit logs
- Core table row counts
- Migration `v91_ops_centre` with operational indexes

## Purpose

This gives Martins a single page to monitor whether imports, royalties, live publishing, notifications, and cached dashboard data are healthy after month-end processing.
