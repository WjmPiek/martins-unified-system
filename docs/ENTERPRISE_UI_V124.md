# Martins Enterprise UI V124

V124 replaces the accumulated page-level styling with one shared enterprise design system.

- Fixed, light professional sidebar on desktop and slide-out navigation on mobile.
- Compact Martins-branded top bar.
- Unified page headers, filter toolbars, buttons, cards, tables and KPI grids.
- Responsive column layouts for executive dashboards, royalty management, insights and analytics.
- Dedicated styles for Insight Explanations tabs, KPI summaries, calculation traces and province cards.
- Existing business logic, permissions, calculations and routes remain unchanged.

No database migration is required.
