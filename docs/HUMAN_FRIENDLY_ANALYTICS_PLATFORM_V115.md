# Human-Friendly Analytics Platform V115

This release layers the requested interface phases over the existing Martins Funeral System backend.

## Included

1. A soft, consistent enterprise design system for typography, spacing, cards, forms, tables, alerts and status badges.
2. A professional role-aware sidebar organised by business purpose: overview, graphs, royalties, franchise intelligence, operations and administration.
3. Dedicated scenario navigation through existing focused routes and `section` query parameters.
4. A shared chart palette: actual, target, forecast, previous year, growth and critical values use consistent colours.
5. Clickable decision cards, quick actions and drill-down links remain connected to the existing routes.
6. Responsive desktop, tablet and mobile behaviour.
7. Existing imports, royalty calculations, permissions, database models and business logic are preserved.

## Deployment

No database migration is required. Deploy the source, restart the Render web service and hard-refresh the browser.
