# Human-Friendly Analytics UI V114

## Purpose
The navigation and visual system were reorganised around business questions rather than technical modules.

## Main navigation domains
- Business Overview
- Graphs & Analytics
- Royalties
- Franchise Intelligence
- Executive Dashboard
- Franchise Operations
- Administration

Each sidebar link now explains what the page represents. Executive Dashboard, Business Intelligence and Royalty Management section links open only the selected scenario through the existing `section` routing.

## Visual improvements
- Martins purple-led colour system with matching chart palette
- Improved heading, paragraph and subtitle hierarchy
- Softer cards, tables, filters, forms and badges
- Clear active menu state and expandable navigation domains
- Responsive mobile sidebar
- Modern graph styling using purple, blue, amber, green and neutral target lines
- More visible clickable cards and links

## Business logic
No database models, royalty formulas, permissions, imports or calculation engines were changed.
No database migration is required.
